# Etapas

Os quatro passos de "Como funciona", cada um com uma barra fina no topo. As barras das etapas feitas e da atual ficam em `marca`; o resto em `linha`. Funciona como um indicador de progresso, sem numerais grandes.

- `<ol class="arco-etapas">` com `<li class="arco-etapa">`; "Etapa N" vem do CSS.
- `is-feita` e `is-atual` pintam a barra. Em carrossel, a barra da atual pode encher com o tempo.
- Quatro colunas no desktop, uma no celular.
