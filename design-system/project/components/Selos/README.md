# Selos

Lista curta de garantias logo abaixo do botão principal, cada uma com um visto em círculo menta. Responde ao medo do paciente sem precisar rolar a página.

- No máximo 3 selos, de 2 a 4 palavras cada: "Sedação consciente", "Plano e valor por escrito", "Sábado de manhã".
- Nunca selo de preço, gratuidade ou parcelamento (CFO).
- Sobre o hero, o texto fica em `sobre-grafite`.
