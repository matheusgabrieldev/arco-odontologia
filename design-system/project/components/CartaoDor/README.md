# CartaoDor

Cartão da seção "Para quem é": um ícone em círculo de fio, a dor em forma de pergunta e uma linha de resposta. Sem borda: o cartão branco se separa da placa só pela cor.

- Título é a pergunta que o paciente faz a si mesmo, em `titulo-cartao`.
- Ícone do conjunto `assets/Icones` dentro de `arco-icone`.
- Três cartões lado a lado no desktop, empilhados no celular.
