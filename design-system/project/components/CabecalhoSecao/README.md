# CabecalhoSecao

Abertura de cada seção: rótulo com ponto quadrado, título em dois tons e uma linha de apoio.

- Rótulo em `rotulo`: frase comum, 14px, com o ponto em `marca` (em `destaque` sobre grafite). Nunca caixa alta.
- Título em `titulo-secao` (Regular). A primeira frase afirma, a segunda (em `<span>`, `texto-suave`) explica ou acalma.
- `is-lado` põe o apoio à direita do título no desktop.
