# PadraoArcos

Textura de arcos repetidos, tirada do símbolo. Use pouco: no fundo da placa grafite do CTA final ou em posts, nunca sobre foto nem atrás de texto corrido.

- Arcos em `marca-suave` com opacidade baixa; um em cada 11 em `destaque`.
- No código, um `<canvas>` decorativo (`aria-hidden`).
