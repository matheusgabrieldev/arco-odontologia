# Botao

Botão em pílula com um ícone num círculo à direita. Rótulo em Figtree 600, frase comum. No hover o botão sobe 1px e o ícone anda; no clique ele afunda; no foco do teclado ganha o anel `foco`.

- **`arco-btn-zap`**: abre o WhatsApp. Sálvia com o círculo claro (`sobre-marca`) e o ícone de conversa em sálvia. É a ação da página; um por tela.
- **`arco-btn-primario`**: grafite com seta, para ações que não abrem o WhatsApp (por exemplo, rolar até os tratamentos com destaque).
- **`arco-btn-claro`**: sobre a placa grafite; branco com o círculo grafite.
- **`arco-btn-contorno`** e **`arco-btn-vidro`** (sem ícone): ação secundária, como "Ver tratamentos". O vidro só vai sobre foto ou grafite.
- Nenhum botão usa âmbar: nem o fundo, nem o círculo do ícone.
- Cada botão de WhatsApp leva a mensagem pronta com um parâmetro de origem (`?origem=hero`) para medir qual seção converte.
