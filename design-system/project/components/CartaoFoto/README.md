# CartaoFoto

Foto grande com legenda sobre um véu grafite no rodapé. Mostra lugar e gente de verdade: a equipe, o consultório, o planejamento na tela.

- Legenda curta: um nome em negrito leve e uma frase.
- `arco-legenda-ilustrativa` marca a foto que ainda não é real (por exemplo, o caso de resultado antes do TCLE).
- Proporção 16:10 no desktop; 4:5 no celular.
