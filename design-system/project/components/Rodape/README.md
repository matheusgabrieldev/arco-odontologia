# Rodape

Última placa, em `grafite`: título grande em dois tons, o botão de WhatsApp, endereço, horário e contato, e a linha legal.

- A linha legal (`arco-legal`, mono) é obrigatória: responsável técnica, CRO e link da política de privacidade (LGPD).
- Mapa como link para o Google Maps, não embutido, para não pesar no celular.
- O ponto do rótulo vira âmbar sobre grafite.
