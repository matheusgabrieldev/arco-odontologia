# CartaoDepoimento

Depoimento com o texto grande (`citacao`) em cima e a pessoa embaixo: foto, nome, fonte e estrelas em âmbar. Na LP os cartões correm em duas fileiras, em sentidos opostos (`arco-faixa-depos`), com as bordas dissolvidas; param quando o mouse ou o foco do teclado entra.

- Cada fileira repete os mesmos cartões duas vezes no HTML para o loop não ter emenda; a cópia leva `aria-hidden="true"`.
- Com `prefers-reduced-motion`, a faixa para e vira rolagem lateral.
- Sem foto autorizada, use as iniciais (`arco-iniciais`), nunca a foto de outra pessoa.
- Nome e foto só com permissão escrita do paciente. Texto como veio, sem editar elogios; corte só o tamanho.
- No portfólio, avatares de banco de imagem e textos fictícios.
