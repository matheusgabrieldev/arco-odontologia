# WhatsAppFixo

O botão `arco-btn-zap` preso no canto de baixo da tela do celular, com `sombra-flutuante`. É o único elemento âmbar enquanto aparece.

- Aparece quando o hero sai da tela, para não repetir o botão do hero; some no desktop, onde o menu cumpre o papel.
- Rótulo curto ("Agendar avaliação") com a seta; nunca só um ícone.
- Respeita as áreas seguras do celular (`env(safe-area-inset-*)`).
