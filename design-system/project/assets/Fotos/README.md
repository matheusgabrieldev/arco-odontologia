# Fotos

Banco de fotos da LP, todas do Pexels (licença livre, crédito opcional; fontes em `fotos/CREDITOS.txt` do projeto). Cada nome diz a seção: `hero-`, `dor-` (Para quem é), `trat-` (Tratamentos), `planejamento-digital` (Como funciona), `caso-resultado` (Casos), `doutora`/`equipe`/`consultorio` (Quem cuida), `depo-` (avatares dos depoimentos).

`caso-resultado.jpg` é ilustrativa: na LP real, troque por caso de paciente com autorização escrita (TCLE). Os avatares de depoimento também são de banco de imagem.
