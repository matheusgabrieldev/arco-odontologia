# Ícones

Seis ícones de traço (1,75px, cantos redondos) em sálvia `#2F5D57`, com um detalhe em âmbar `#E3A03A`: implante, lentes, clareamento, planejamento, agendar e conversa. Use em 24–32px dentro do círculo `marca-suave` (CartaoDor) ou ao lado de rótulos. Sobre fundo escuro, use a versão inline do brandbook com `currentColor`.
